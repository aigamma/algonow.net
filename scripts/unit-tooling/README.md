Catalog integrity audit (2026-10-15):
- `node scripts/unit-tooling/render_audit_report.mjs [input.json] [output.html]` renders the saved audit record as a searchable, standalone HTML report. It does not change puzzle content or publish the report.
- `npm run check` includes `narration-currency.test.mjs`, which rebuilds every installed recorded lesson's canonical plan and rejects stale source, recipe, or release bindings before deployment.
- `node scripts/unit-tooling/audit_catalog.mjs --output build/audit/catalog.json` renders every registered page through the real `PuzzlePage`, checks installed narration manifests against canonical source and receipt inventories without credentials, and runs every exported `makeScene`/`sceneTick` model over 20 seeds. The report lists model coverage gaps explicitly. `--cycles` and `--seed` override the defaults. It does not audit the factual accuracy of prose, exercise browser drawing, or contact published media.
- `vizcheck.mjs` checks the initial scene and every tick, including the completing tick, and exits nonzero on invariant failures. It supplies the required alternate scene arguments for CG, Gaussian elimination, Grover, and parallel scan. Both drivers use `scene-check.mjs`.
- `node scripts/unit-tooling/audit_canvas_callbacks.mjs --output build/audit/canvas.json` captures every registered visualization's actual `useCanvasLoop` callbacks, exercises 20 reset cycles in still mode, and invokes each terminal draw with a no-op canvas context. It detects callback exceptions, incomplete runs, top-level invariant failures, NaN state, and invalid drawn values. This exercises real simulation callbacks, including legacy modules without exported models; it does not inspect rendered pixels or browser effects.
- `node scripts/unit-tooling/check_entry_modules.mjs --output build/audit/entries.json` executes actual preserved-audio entry modules against their installed manifests and separately against pending manifests substituted only in generated audit bundles. Every pending entry must reject rendering, preventing browser-speech fallback.
- `node scripts/unit-tooling/audit_canvas_text_bounds.mjs --canvas-module /path/to/@napi-rs/canvas --font /path/to/monospace.ttf --cycles 2 --output build/audit/text-bounds.json` measures real glyph bounds at initial, quarter, middle, three-quarter, and final animation states. `--from` and `--to` restrict puzzle numbers. It fails for clipped text, callback errors, or source changes during verification. The native renderer is an optional audit dependency, never a website dependency. This check covers canvas edges; internal overlaps, colors, and explanatory correctness still need image and browser review.
